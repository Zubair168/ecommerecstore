# Asset Inventory

This inventory documents all reusable vector (SVG) and raster (PNG) assets extracted from the Online Shop Figma Community UI Kit for Flutter development.

All assets are located inside `assets/raw/` organized by functional subdirectories.

## Asset Directory Structure

```
assets/
└── raw/
    ├── avatars/
    ├── banners/
    ├── categories/
    ├── icons/
    ├── illustrations/
    ├── images/
    ├── logos/
    ├── misc/
    ├── navigation/
    ├── payments/
    └── products/
```
